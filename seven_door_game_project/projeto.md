# Projeto Seven Door

## Resumo

O Seven Door é um jogo índie em que você é um explorador que precisa encontrar 7 chaves para poder destrancar a porta principal e fugir pela saída central do jogo, zerando assim o jogo

## Classes/Objetos

Classe Mundo:
    Essa classe é responsável pela geração do mundo em que se passa o jogo.

Classe sala:
    Essa classe é responsável pela geração de cada uma das 7 salas onde estão escondidas as chaves.

Classe personagem:
    Essa classe é responsável por defenir as características e funções do personagem. Na ideia inicial do projeto, usaremos essa classe para definir o personagem principal do jogo, que é controlado pelo usuário.

Classe objetos:
    Essa classe é responsável por definir um objeto de forma geral como móveis, portas, chaves, bússolas e etc, sem interação ou habilidade. 

Classe objetos interagíveis:
    Essa classe é responsável por definir os objetos que são interagíveis, herdando características da classe objeto. Por exemplo: portas, chaves e moedas.

Classe objetos especiais:
    Essa classe é responsável pelos itens que, além de interagíveis, fornecem uma habilidade especial sobre o usuário. Por exemplo: o chapéu de mago, que aumenta a velocidade do personagem em 50%.
